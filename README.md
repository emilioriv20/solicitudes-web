# Sistema de Gestión de Solicitudes - Frontend (solicitudes-web)

Aplicación cliente desarrollada en React + Vite para la gestión e interacción en tiempo real con la API de solicitudes REST.

---

## 🛠️ Tecnologías y Características

- **Librería/Framework:** React 18 con Vite.
- **Cliente HTTP:** Axios.
- **Gestión de Estado Centralizado:** `useReducer` y Context API (`SolicitudesContext`).
- **Control de Cancelación:** Manejo de peticiones asíncronas con `AbortController`.
- **Filtro Local:** Búsqueda rápida y reactiva en el cliente por descripción y estado.
